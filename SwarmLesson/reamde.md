# Intro to Docker Swarm 

Docker Swarm - это инструмент для управления кластером Docker хостов. Он позволяет объединить несколько Docker хостов в один кластер и управлять ими как одним целым.

Давайте предположим, что у нас есть приложение, написанное на .NET Core с использованием React, Redis, Nginx. Мы можем развернуть это приложение на одном Docker хосте, но что если у нас есть несколько Docker хостов и мы хотим развернуть это приложение на всех них? Вот где Docker Swarm приходит на помощь.

Для использования Docker Swarm достаточно иметь установленный Docker Engine. `docker swarm init` - команда для инициализации Docker Swarm. После инициализации, Docker Swarm создает кластер из одного Docker хоста. Для добавления других Docker хостов в кластер используется команда `docker swarm join`.

Docker Swarm поддерживает два режима работы: `replicated` и `global`. В режиме `replicated` контейнеры запускаются на всех Docker хостах в кластере, а в режиме `global` - на каждом Docker хосте.
