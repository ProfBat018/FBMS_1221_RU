Вам надо сделать программу, которая скачивает все постеры 
фильма по запросу пользователя и сохраняет его в этом контейнере

Каждый должен работать в своей папке. Также вы должны создать 
подпапки по названию фильма по которому идет поиск. 

Пример: Пользователь ввел Batman

У вас будет путь если вы Мага, Maqa/Batman/{название постера}.jpg

Неважно сколько постеров есть у каждого фильма. Все постеры должны туда попасть

Также вы должны сделать возможность скачивания этих файлов в формате .zip архива с 
вашего blob контейнера. Для поиска фильмов можно использовать любой api, я советую tmdb
