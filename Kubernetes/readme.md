# Введение в Kubernetes & Secret Manager

`Kubernetes` - это платформа для автоматизации развертывания, масштабирования и управления контейнеризированными приложениями. Она позволяет упростить процесс развертывания и масштабирования приложений, управлять ресурсами и автоматизировать процессы.

`Secret Manager` - это инструмент для управления секретами, такими как пароли, ключи API и сертификаты. Он позволяет хранить секреты в безопасном месте и предоставлять к ним доступ только авторизованным пользователям.

# Введение в Kubernetes

`Kubernetes` был создан компанией Google в 2014 году. На данный момент он является одной из самых популярных платформ для управления контейнеризированными приложениями.

Сразу разберем разницу между `Docker Swarm` и `Kubernetes`. `Docker Swarm` - это инструмент для управления контейнерами, который входит в состав Docker. Он позволяет развертывать и масштабировать контейнеры, но не обладает такими возможностями, как `Kubernetes`.

В `Kubernetes` есть несколько основных компонентов:

- `Master Node` - это главный узел, который управляет кластером Kubernetes. Он отвечает за планирование задач, мониторинг состояния кластера и управление ресурсами.
- `Worker Node` - это рабочий узел, на котором запускаются контейнеры. Он отвечает за выполнение задач и обеспечение доступности приложений.
- `Pod` - это минимальная единица развертывания в Kubernetes. Он содержит один или несколько контейнеров, которые работают вместе.
- `Deployment` - это объект, который определяет, какие контейнеры должны быть развернуты и как они должны быть масштабированы.
- `Service` - это объект, который определяет, какие контейнеры должны быть доступны извне кластера.

# Установка Kubernetes

Для установки Kubernetes на локальной машине можно воспользоваться `Minikube`. Он позволяет развернуть локальный кластер Kubernetes для разработки и тестирования приложений.

Для установки `Minikube` нужно выполнить следующие шаги:

1. Установить `kubectl` - это инструмент для управления кластером Kubernetes.
2. Установить `Minikube` - это инструмент для развертывания локального кластера Kubernetes.

После установки `Minikube` можно запустить локальный кластер Kubernetes с помощью команды `minikube start`.
