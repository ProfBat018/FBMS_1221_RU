# Docker deploy to Azure 

Сегодня мы с вами разберем как можно сделать 
`deploy` нашего приложения на сервер с помощью `docker`
контейнера. Но для начала нам с вами надо разобрать 
что такое `docker` и `контейнеризация` в целом. 

## Контейнеры и их роль 

Представьте себе `.iso` файл, с помощью которого вы обычно устанавливаете себе операционную систему или пиратские программы. По сути это образ диска или виртуальный носитель. 

А теперь давайте представим что мы можем взять за основу 
операционную систему `Linux` и с помощью виртуализации ставить туда любые подсистемыю Давайте разберем пример...

Предположим у меня есть обычный компьютер на `Windows`, 
на который я должен установить `Sql Server` и `dotnet`.
Я устанавливаю себе на компьбтер `Docker`, который по умолчанию устанавливает мне `WSL2`(Windows Subsystem For Linux) и тем самым каждый рах при запуске `Docker` по сути вы запускаете еще и `Linux`. В сам `docker` мы можем скачивать образы с официального сайта `docker hub`. Когда я говорю `образ` вы как раз можете представить себе тот самый `iso` файл.
